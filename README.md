# 🥭 Crazy Mango's (Premium)

Landing page interactiva para **Crazy Mango's** — mango, maracuyá y chamoy en El Pando, Santa Marta.

## 🌐 Visualización en vivo (GitHub Pages)

**→ [https://dsrueda3691.github.io/crazymangos/](https://dsrueda3691.github.io/crazymangos/)**

## Stack

- Next.js 15 · React 19 · TypeScript
- Three.js + @react-three/fiber + drei
- GSAP + ScrollTrigger
- Framer Motion · Tailwind CSS

## Desarrollo local

```bash
npm install
npm run dev
```
